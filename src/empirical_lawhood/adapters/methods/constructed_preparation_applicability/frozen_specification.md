## Question and scientific value

Does an evidence-selected upstream preparation produce valid, useful use of
unchanged F on fresh preparations deliberately constructed near an identified
support failure? Compare N against equal-duration native HOLD, with P retained
as the other existing bounded preparation. This tests fixed preparation
production, not adaptive superiority over N itself. The learned component is
the evidence-based nomination of the construction and N; no new learner is fit.

The competing explanation is that waiting already supplies applicability, or
that N crosses a support face while lower prediction, coverage, preservation or
use still fails. The missing operand is fresh independent response evidence in
a declared incoming population with reproducible support-repair opportunity.
The [completed nomination audit](../results/cc1-applicability-production-opportunity-v1-2026-10-01.md)
found one measured repair and a consistent N-minus-HOLD force-rate reduction,
but no useful causal selector for that rare failure in the ordinary population.
This plan changes the incoming source distribution explicitly rather than
pretending a new unselected panel supplies substantial headroom.
