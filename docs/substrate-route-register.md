# Scientific route register

SPDX-License-Identifier: CC-BY-4.0

This register gives information about retained scientific routes, attached methods and removed custody wrappers.
It owns each route’s present operation and evidence ceiling.
Use it to find a workflow, its source checks and its first honest stop.

## Scope and operation

Reactor, analytical RC and the matrix paper-study routes define the current bounded integration scope.
Other unfinished integrations retain their stated stops.
Checked development workflows remain available at their stated ceilings.
Prospective physical RC, inverter, building-control and external electron-material routes were removed from this release scope.

Static registration, provider construction, native completion, qualification, admission and permitted use are separate states.
An authoring link requires editable inputs and a checked candidate boundary.
Input validation grants no native execution or scientific authority.
Development results remain exposed.
Nested solver views, conditions and observations do not add independent preparations.

The retained-source crosswalk contains 93 source-register entries.
They contain 74 scientific routes and 19 attached method or custody-wrapper entries.
The post-hoc paired response-composition route appears with its parent-dependent methods because it has no native substrate.
The [complete system inventory](release-inventory.md#systems-and-current-states) projects these entries into current-system rows and historical physical-result rows.
The external review packet retains the exact source-entry crosswalk.

Use the [environment guide](environments.md) for dependency profiles.
Use the [CLI reference](cli.md) for exact names, formats and effects.
Use the [paper source register](../paper/SOURCES.md) for historical results and their deposition limits.
