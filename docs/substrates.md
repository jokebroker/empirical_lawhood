# Scientific systems and their boundaries

SPDX-License-Identifier: CC-BY-4.0

This reference gives information about the physical, numerical and reference systems retained by the engine.
It distinguishes native sources from methods that consume their observations.
Use it to select a scientific system and its checked workflow.

## Select a system

The [complete system inventory](release-inventory.md#systems-and-current-states) gives the compact capability and evidence inventory.

Use the [environment guide](environments.md) for exact dependency profiles.

## Adapter and method ownership

A native adapter owns source qualification, preparation, action delivery, clocks, units and receivers.
A method owns a scientific estimand over declared typed inputs.
A composition binds those contracts with lineage, resources, custody and authority.
Static descriptors advertise possible ceilings.
They supply no separate native source or independent preparation.

The [architecture map](architecture.md) locates these owners.
The [extension procedure](extending-the-engine.md) gives descriptor and executable-binding registration.
The [general experiment guide](designing-and-running-an-experiment.md) gives the shared lifecycle.
Each experiment bundle owns its actual editable input and checked command.
