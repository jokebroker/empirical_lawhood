# Glenn 2026 retrospective archive boundary

SPDX-License-Identifier: CC-BY-4.0

This assessment gives information about the published laser-burst archive and its retrospective transform.
It bounds the local inspection route without live actuation or prospective qualification.
Use it to identify the exact archive, independent burst and missing custody handoff.

The retained Glenn adapter consumes the [official Zenodo 17163053
release](https://zenodo.org/records/17163053) (DOI
10.5281/zenodo.17163053), an outcome-visible physical archive. It imports
logged burst observations and source model data. It does not command a laser
or create a new prospective physical preparation. The independent unit is one
burst.

The ten shots nested within each burst do not create ten units. The current official record declares CC BY 4.0 for the archive. An authorized
researcher must retain its attribution and source notice.

The adapter's `GLENN_2026_PROFILE` pins the 549,154,725-byte ZIP, its
SHA-256, four exact non-executing members, per-member hashes, formats and
expansion limits. The external official archive passed the exact decoder and produced 101 rows and 20 columns. Its logical table SHA-256 is
`9060bfac2703d923f03d0429707eb520b8a2cf56f2d097b636236e8f55713979`. An independent read of the selected NumPy member confirmed the source
notebook's ×1000 focal-radius conversion into micrometers.

The prior-fitness column
lagged the observed fitness by one burst, with the first history marked
missing. The first burst retained zero command values. A deliberately wrong
declared archive size refused before any payload read. The archive and selected
bytes were not copied into the package.

The [strict local input guide](../../experiments/laser-archive-inspection/guide.md) now gives a
single-CLI preview and read-only import check over a researcher-held copy of
the exact release. The [focused authentic-source check](../../tests/test_glenn_authentic_source.py)
can be run after obtaining the official ZIP and placing it in guarded external
storage. From the target checkout, set `GLENN_PUBLIC_ARCHIVE` to that local
file and run `uv run --no-sync pytest -q
tests/test_glenn_authentic_source.py`. It skips when the archive is not
supplied. It never downloads, writes or extracts the archive. This is a
scientific adapter check, distinct from the local inspection's custody and
authorization limits.

This check establishes the exact retrospective transform, not a fresh
physical response result. The profile records three limits: focal-radius
generation method and uncertainty are unavailable, and the deposited action
labels have a source-notebook caveat. The deposited model log is source
validation input, not a pre-burst prediction. Obtain the official archive under its access terms.

Keep it beneath an external guarded storage root. Provide its exact source, custody and outcome-visibility records. The
retained production manifests express those requirements. The installed CLI validates the exact archive and transform.
It publishes no guarded source receipt or typed outcome-visible authorization to those manifests.

No
candidate, provider or no-effect proof is claimed for this post-hoc path.
That further integration is deferred for the first release.
