These implementations retain separate family records, schemas, scientific
budgets, globals and authority routes. Similar function bodies do not establish
interchangeable scientific contracts. The parent research checkout is a
read-only provenance reference; the installed public package is independent.

The reactor causal checker independently reconstructs producer endpoints and
inference. The six-matrix literal reference and optimized gradients remain
independent verification paths. Neither was replaced by a shared producer
helper. Fixed input tables, exposure censuses, seed commitments and historical
provenance constants retain their exact scientific meaning.
Realized future trajectories used by tangent and measured-HOLD diagnostics remain evaluator-only.
They do not enter pre-parent causal features or nominated forecasts.

The forecast families resolve their own `PREFIX`, `BUDGET`, `RECEIVERS` and
`UNITS`, and separately owned `ReactorForecastDesign` and `ReactorBatchConfig`
schemas. Each quantum family owns its denominator, action, view and trajectory
result types with its checkpoint and PRNG contracts. The rank families retain
`ReceiverHistoryDiscreteRankBracket`, `SplitCohortHistoryBudgetDiscreteRankBracket`
and `HistoryBudgetPhaseDiagramDiscreteRankBracket` with one shared numerical certificate.
The [scientific integrity guide](scientific-integrity.md#rigorous-threshold-rank) states its mathematical target, proof obligations and evidence limits. The Student paths assemble separate
`ControllerUnitEvaluation` and `NestedControllerUnitEvaluation` records.

The small locator import seam now uses `kernel.serialization` directly in
runtime plans and catalog; the existing `runtime.artifacts` re-export remains
the same function. This changes ownership references without changing locator
acceptance, scientific algorithms or canonical products.

Any future numerical consolidation needs a separate comparison plan covering
trajectories, random draws, checkpoints, operation order, tolerances, failures,
consumer decisions and canonical products. Static similarity and a green
software gate provide no scientific equivalence proof.
