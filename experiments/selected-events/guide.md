## Reconstruct the nominated context or declare an alternate

Use the [locked base environment](../../docs/environments.md) and an explicitly
selected guarded [storage profile](../../docs/configuration.md). The supplied
[parent.json](parent.json) binds current mathematical owners and the actual lock.
The baseline reconstructs the fixed q2, joint-increasing, mass .5/cross-coupling 1,
grid(1,11), seed slot 1 parent using its original authenticated full driver. Its
exact final-state hash must agree. That driver is exposed conditioning context;
the opaque historical C0 reference conveys no current qualification.

```bash
uv run --no-sync empirical-lawhood --project-root /selected/checkout \
  --operator-profile /work/operator-profile.json campaign selected-parent-reconstruct \
  --input /work/parent.json
```

Copy the supplied parent input first, or use canonical configuration consumer
`selected-parent` when editing permitted fields. Absence, invalid numerics,
no admitted geometric event or a nominated driver/final-state mismatch stops
conditioning. The workflow does not search for a favourable replacement.

A separately named parent request can explicitly select an actual valid row of
a complete current [geometry scan](../matrix-geometry/guide.md). Recurring-regime
success is not required for that conditional instance:

```bash
uv run --no-sync empirical-lawhood --project-root /selected/checkout \
  --operator-profile /work/operator-profile.json campaign selected-parent-alternate \
  --input /work/alternate-parent.json --geometry-input /work/qualified-scan.json \
  --rollout-id SELECTED_ACTUAL_ROLLOUT_ID
```

The alternate retains its actual scan, row and source identities. It cannot
replace an already retained parent of the same request.

  --operator-profile /work/operator-profile.json campaign selected-events-prove \
  --input /work/selected-event.json

matched-amplitude target comes from the authenticated parent's measured radius;
historical null counts and a literal old radius are not new-data operands.

The proof reconstructs the installed native owner, source/input custody and
full resource census without running branches. Checkpoints are 816,848,880,896,
928,960 and1024; formation/admission roles and linearization at 896 remain fixed.
Each future uses HOLD for1,024 steps, cadence 16, window 16 and persistence 12.

## Bounded conformance, investigation and retained results

The conformance command performs one actual parent replay/checkpoint restart and
one declared conditional future. It retains exact receipts and does not complete
the seven cohorts or qualify the event:

```bash
uv run --no-sync empirical-lawhood --project-root /selected/checkout \
  --operator-profile /work/operator-profile.json campaign selected-events-conformance \
  --input /work/selected-event.json --checkpoint-step 896 --branch-index 0
```

The full run performs the declared investigation only when that acquisition is
intended. Same-driver half-step checks split original coarse innovations through
the source-defined Brownian bridge. They are not an independently sampled path.
A numerically view-sensitive event stops shooting and local linearization, and
retains those condition-false descendants and the negative terminal.

```bash
uv run --no-sync empirical-lawhood --project-root /selected/checkout \
  --operator-profile /work/operator-profile.json campaign selected-events-run \
  --input /work/selected-event.json
uv run --no-sync empirical-lawhood --project-root /selected/checkout \
  --operator-profile /work/operator-profile.json campaign selected-events-result \
  --input /work/selected-event.json
```

Forward branch diagnostics use only postcheckpoint future samples. Invalid,
unresolved and censored futures remain in their assigned 64-future denominator.
No ambiguous-result top-up is performed. Reports retain separate numerical,
committor, residence, stability and descriptive-null axes; a favourable null
cannot compensate numerical failure. The CLI emits a bounded scientific summary.

Result reading authenticates exact current parent/source, terminal/dependency
fingerprints and all assigned completed branch receipts. Recovery reuses exact
positions, momenta, stream state and retained original innovations; the clock
and locked source/config remain part of the checkpoint. Repeat the same command
and exact input to reuse completed cells. Interrupted contact without a completion
receipt stops for inspection rather than repeating uncertain effects. Producing
Git commit, actual scientific owner/lock identities and runtime observation are
distinct retained attribution; development outputs grant no issue/reveal authority.
