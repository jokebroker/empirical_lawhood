## Inspect the external scalar parent

Obtain the local [input selection](analysis-input.json), then run from the checkout root with a selected operator profile and absolute parent/authority paths:

```sh
uv sync --locked --python 3.11.14
uv run --no-sync empirical-lawhood --project-root "$PWD" \
  --operator-profile "$OPERATOR_PROFILE" campaign response-composition-input-check \
  --config experiments/causal-transfer-audit/analysis-input.json \
  --source-root "$PREPARED_RESPONSE_HELD_SOURCE_ROOT" \
  --parent-manifest "$PREPARED_RESPONSE_PARENT_MANIFEST" \
  --custody "$PREPARED_RESPONSE_PARENT_CUSTODY" \
  --reveal-record "$PREPARED_RESPONSE_PARENT_REVEAL" \
  --analysis-record "$PREPARED_RESPONSE_PARENT_ANALYSIS"
```

The bundled selection fixes the exposed role. Keep its original parent census, absolute channels, finite features and work. A new path or namespace cannot create custody or qualified evidence. See the [parent import procedure](../../docs/response-input-formats.md) for publication and guarded-store prerequisites.
